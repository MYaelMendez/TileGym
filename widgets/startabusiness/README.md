# #startabusiness agentic widget

Canonical Studio implementation for the #startabusiness business-preparation surface.

## Purpose

Turn entrepreneurial intent into a reviewable, owned business blueprint while keeping the human principal in control.

```text
HUMAN://principal
  → first-sale intent
  → #startabusiness widget
  → GitHub-owned blueprint
  → reviewed environment
  → provider formation handoff
  → HUMAN://value ❤️
```

## Action gate

Repository actions are enabled only when both gates are ready:

```text
ChatGPT identity = authenticated
AND
GitHub = connected + authorized
--------------------------------
repository action widgets = enabled
```

This does not authorize merge, deployment, publication, payment, formation filing, or disclosure of private founder information.

## Canonical states

- identity gate
- GitHub connection gate
- blueprint status
- classification status
- formation handoff status

## Formation handoff

The widget may expose the user-confirmed doola referral only when the entrepreneur is ready for onboarding. The handoff is affiliate-disclosed and provider-controlled. A referral URL does not prove conversion attribution.

## Files

- `types.ts` — portable widget state/action contract
- `widget.tsx` — React surface
- `README.md` — operating contract

## Invariant

**Action widgets are not decoration.**

Many agents. One principal. Context may propagate; authority does not.
